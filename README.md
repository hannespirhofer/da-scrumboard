# **Scrumboard App 📌**

A simple **Scrumboard** with **Login**, **Tasks**, and **Drag & Drop** for managing tasks.

---

## **🔹 Features**
✔ **Login** (User auth for boards)
✔ **Tasks** (Create, edit, delete)
✔ **Drag & Drop** (Move tasks between columns)
✔ **Boards** (Manage multiple boards)

---

## **🔹 How to Run 🚀**
```bash
git clone LINKTOREPO
cd scrumboard/frontend
npm install  # Install frontend deps
cd scrumboard/backend
pip install -r requirements.txt  # Install backend deps
```
Run Backend:
```bash
cd scrumboard/backend
python manage.py runserver
```
Run Frontend:
```bash
cd scrumboard/frontend
npm start
```

Use **localhost:4200** to open the project. (or check terminal for different domain and port if so)

---

## **🔹 Tech Stack 🛠️**
- **Frontend:** Angular
- **Backend:** Django
- **Database:** SQLite

---

## **🔹 Drag & Drop 🖱️**
Use **drag and drop** to move tasks inside board columns.
